### 目前现状 

让新旧事实更加准确的配对 ， 之后进行更新决策 和后续的回答   都会回答具体的证据进行检查  



证据驱动更新 ---- 版本化保存 --- 按照时间回答  




一、我们目前做到了哪里？
| 部分 | 当前状态 | 已经发现的问题 |
|---|---|---|
| **证据与数据适配** | 已有原型，可关联部分原始对话和时间信息 | 证据定位、时间精度及数据集适配仍需完整验证 |
| **事实抽取** | 已实现候选事实抽取和语义审查原型 | 可能抽错主体、把计划当成事实，或提取出原文不支持的内容 |
| **新旧事实配对** | 已从整句语义相似检索，改为尝试按事实属性配对 | 候选看起来更合理，但目前只做了很小规模开发验证，且规则见过目标样本 |
| **事实关系判断** | 已有判断变化、补充、共存等关系的原型 | 模型仍可能把不确定描述判断为确定变化 |
| **记忆更新** | 可以给出更新建议或暂缓决定 | 尚未完成可信、可回溯的实际更新闭环 |
| **回答生成** | 做过少量证据和关系辅助的回答诊断 | 尚未证明比原始基线更好，也没有完成系统化证据验证 |


系统根据什么证据更新证据   以及如何影响回答 


研究问题: 在长期个人对话中，当用户对同一生活事实出现新的陈述时，如何判断新陈述与已有记忆的关系，基于原始证据更新或保留记忆，并在后续问题中使用相应时间和条件下有效的事实？


问题 1: 哪些新旧事实值得比较   如何找到更准确的变化记忆

策略  同一主题 ，同一事项 或者属性下，可能存在关系的新旧事实 


问题二： 找到事实后， 记忆如何更新 

记忆之间可能存在多种关系  


| 旧陈述 | 新陈述 | 应考虑的关系 |
|---|---|---|
| 我住在上海。 | 我现在搬到北京了。 | 有明确变化线索，可考虑更新当前状态 |
| 我住在上海。 | 我打算搬到北京。 | 计划，不证明已经搬家 |
| 我住在上海。 | 我在北京出差。 | 条件和事件不同，可以共存 |
| 我住在上海。 | 我之前说错了，我一直住在北京。 | 明确纠正，需要保留纠正依据 |
| 粉丝有 1250 个。 | 我觉得现在接近 1300 个。 | 新的近似陈述；可用于近似回答 约1300，但不能自动视为精确值或确定增长原因 |

判断关系和决定写入 ， 是两个步骤 



问题3： 之后回答是应该使用那条信息呢  
“我现在住在哪里？” → 优先选择当前有效状态。
“我搬家前住在哪里？” → 检索历史状态。
“我是什么时候搬家的？” → 只有原文支持时才能给出时间。
“为什么你认为我搬家了？” → 能追溯到对应原始陈述和更新依据
