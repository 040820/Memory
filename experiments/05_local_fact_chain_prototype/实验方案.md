# 05 本地独立事实与变化记录原型

状态：开发中。本地独立实现；服务器实验编号和代码恢复连接后须核对。

目的：保留原实体图，以独立事实、原始证据和事实间变化记录验证保存及双向查找。变化记录只保存审查决定，不自动判断事实或更新当前状态。无模型调用、无真实数据实验，不改动基线检索。

验证：不同来源和不同关系独立保存；同一来源重复写入幂等；依据 ID 无效时拒绝；变化记录可由两端事实找回；存储重载后不丢失。

## 当前结果

本地单元测试通过：4 项。独立原型不依赖 MultiDiGraph，按主体及精确关系检索事实，按任一事实 ID 查询变化记录；支持字典导入导出。证据仅校验 ID 存在，不代表原文支持；变化记录不会自动修改状态。
