# 实验 01：语义审查分歧分析

## 分析范围

依据两次既有受控运行的逐条输入、原始模型响应、`implementation/evidence_memory/semantic_review.py` 与 `fixtures/semantic_review_controlled_expected.json` 静态复核。没有重跑模型、修改提示词、改写期望标签或覆盖既有结果。受控期望是实验时人为编写的初始约定，不是独立人工金标准。

## 逐条检查线上模型的语义分歧

| 案例 | 原文与候选 | 原期望 / 线上输出 | 分析 |
|---|---|---|---|
| `control_other` | 姐姐是教师；候选称用户是教师 | contradicted / supported | 理由明确说职业属于姐姐、不能归于用户，但 `semantic_support` 填 supported。提示没有明确判断的是含主体的完整候选，还是只判断“某人是教师”的内容。因此这是提示和字段定义歧义，模型结构化字段也与理由不一致；不能确定唯一根因。主体字段 `other_person` 确认，现有门控 DEFER。 |
| `control_plan` | 明年计划搬到上海；候选称现在住上海 | contradicted / insufficient | 未来计划不证明现在住在上海，但也未直接否定现在住在上海；insufficient 更稳妥。原期望 contradicted 过强，提示缺少 contradicted 与 insufficient 的判别定义；现有门控 DEFER。 |
| `control_uncertain` | 将来可能搬上海；候选称现在住上海 | contradicted / insufficient | 同理，原文未证明但未直接否定当前状态；insufficient 更稳妥。模型把 might/someday 标 plan，而理由说可能性，说明 plan 与 uncertain 分类标准也未明确；现有门控 DEFER。 |

此前对线上模型“语义 4/7 与期望一致”的统计可复现，但其中至少两条差异不能简单当作模型错误；原结果仍保留，暂不修改历史统计。

## 其他发现

1. **主体字段缺乏正交定义。** `subject_support` 的 `supported` 容易被误解为整个候选成立；8B 在计划、否定、数量误读中，理由明说主体为用户却选 `other_person`。不能仅据此断定模型能力不足，也不能把提示解释为唯一原因。
2. **语义字段缺少判定边界。** 需要规定其审查“包含主体、属性、值、极性、时间与模态的完整候选”，并区分直接支持、明确矛盾、证据不足。`not supported` 不等于 `contradicted`。主体字段与语义字段冲突不宜直接认定理由一定正确，应保留冲突并暂缓。
3. **时间、模态和极性混为一个枚举。** `current/past` 是时间指向，`plan/hypothetical/uncertain` 是模态或不确定性，同一陈述可能同时具有未来时间、计划及不确定性；“不再住北京”同时包含当前否定和过去状态，单枚举会丢失信息。应分开时间、时态/模态、极性，未知保持未知。
4. **数量案例的原期望亦有问题。** “超过四人很难坐下”不严格等于“只能坐四人或更少”；两个模型都把“难”推断为“不可能”。`table capacity = more than four people` 也未定义是可挤下、舒适容量还是硬上限。候选本身含糊，不能仅因原期望和模型一致就判为严格矛盾。更稳妥是 evidence insufficient / 需求明确容量定义，并用明确“最多四人”的独立案例测试矛盾。
5. **现有规则仅是保守路由而非语义验证。** `parse_review` 只检查标签、引述在原文中存在，然后对 supported/current-or-past/supported 标记 eligible_for_further_review，其他 DEFER。它不核实模型判断和理由一致，也不检验容量、身份与上下文。eligible 不是通过或授权更新；不同模型导致暂缓，不代表规则语义正确。
6. **案例与标签局限。** 7 条是开发诊断样本，未人工独立复核、覆盖不全；语义数值依赖含歧义标签。开发修订与未来留出的盲测样本必须隔离。真实候选还需有足够的上下文和独立审查，不能把 gold 答案喂给抽取或审查。

## 建议的修订（尚未实施）

- 重新规定审查对象和标签：单独回答原文中属性属于 user/other/unknown；完整候选为 supported/contradicted/insufficient；时间、模态和极性分别表示；添加未知与证据片段。
- 在策略层让 subject=other/unknown、完整候选非 supported、缺少时间/模态或模型结构不一致时进入 DEFER；对“过去”允许作为历史事实，不自动作为当前状态。
- 重写有歧义的控制案例，保存旧版本；明确标注依据，将修订样本和独立盲测分开，并分别报告字段匹配、DEFER/误拒及真实候选人工复核。比较两个模型时使用同一输入、提示和规则；不同模型输出仍不是独立真值。
