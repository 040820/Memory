# 实验 01 实施计划

**目标：** 在隔离快照中实现证据追溯、影子决策、受控状态提交和基于证据的回答，保留基线模式。设计见 `代码修改设计.md`。原仓库没有 Git，使用 `源码快照清单.json` 固定源文件哈希，不覆盖原代码与结果。

1. 证据与事实：为原始文本建立稳定 ID、精确引用和独立事实记录；拒绝缺失来源、引用不匹配与覆盖；测试跨会话、独立来源和重放。
2. 演化 shadow：基于明确候选的主体/属性/范围/时间/模态和原文支持进行关系提议及门控；默认 off，shadow 不提交状态；验证计划、否定、多值、冲突及不确定性。
3. 状态提交：版本、决策、幂等、预期 revision、一致持久化；active 默认关闭，门控不足不提交；测试故障与重放。
4. 查询证据：区分 known_at 和 valid_at，按问题获取状态和证据并验证回答引用；未来来源不可见、未知时间不伪造。
5. 接入 LiCoMemory：保持 off 原路径；shadow/active 独立配置和持久化，保留原始关联图；对照测试及故障处理。
6. 校验与记录：测试受控场景、失败注入和端到端开发预检；记日志、输入哈希和结果；公开数据实验需单独按实验方案执行，不将预检当作效果。

每步先写失败测试再实现；原始事实、候选相似度、模型意见和更新充分性分开。不得擅自加整体运行时限；不读取 gold 构建或回答。
