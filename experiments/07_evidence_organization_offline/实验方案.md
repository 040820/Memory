## 设计选择

1. **Chunk ID** = hash(session_id, 顺序)：跨 Session 同原 ID 不覆盖；同 Session 完整重放幂等，新序号追加接受，同序号内容变化拒绝。`source_chunk_id` 是**本次处理的临时序号**（整批=全语料序号、单 Session=从 0 重计），仅作溯源元数据，**不参与冲突比较**（`chunk_conflicts`）；整批→单 Session 重放因此保持幂等。
2. **事实 ID** = hash(src, relation, tgt, evidence_id)：同实体不同关系、同关系不同来源均独立保留；`raw` 原始谓词与实体原样保存，canonical 仅作索引别名。
3. **捕获时机**：实体映射之后、关系去重之前；去重只影响图侧，证据库不受影响。
4. **变化记录（审查事件模型）**：仅允许 candidate + 有来源 + 有原因。每次 `add_change` = 一条事件：`change_key` 标识逻辑变更链，`revision` 在链内递增（`keep→replace→keep` 三条全保留），`seq` 全局递增（`trace` 按其返回，最新决定可判定）。重试幂等单独走 `review_id`：同 `review_id` 重放返回原记录，同 `review_id` 改决策报错；不传 `review_id` 每次调用都追加（历史优先）。加载时 version 1/2 按各自旧公式校验完整性后重编码为事件（version 3）。
5. **complete 语义**：开关开且新构建 = 完整；开关关 / 无 evidence 键的旧 pickle / 旧格式 pickle = 不完整，不虚构恢复结果。
6. **开关关闭** = 原版行为不变（含原版 add 模式跨 Session chunk ID 冲突的既有缺陷，本次不在关闭路径修复）。
7. **召回入口** = 图匹配实体 ∪ 原始查询实体：实体未进图、被图清理或图匹配未命中时，问题中直接提到的实体仍可命中证据索引。

## Codex 审查修复（2026-11-03）

1. **[高] 整批与单 Session 重放误判冲突**：`source_chunk_id` 是处理方式相关的临时序号，却被纳入 `add_chunk` / `chunk_storage` 的整字典比较。修复：新增 `chunk_conflicts`（排除 `source_chunk_id`）统一用于两处比较，抽出 `DynamicMemory._check_chunk_collisions`；新增整批→单 Session 重放测试（存储层与 `add_single_session` 真实路径各一项）。
2. **[高] 同键变化记录不同决定互相覆盖**：`decision` 原不入 ID。修复：`decision` 入 ID（version 2），同键同决定仍幂等、不同决定独立追加；`from_dict` 兼容 version 1（旧公式校验后重编码），新增 v1 加载与双决定历史测试。
3. **[中] 图外事实不可达**：证据候选入口只有图匹配实体。修复：查询结果侧并入**原始查询实体**（`query_processor.py`），新增"实体不在图、问题提及该事实仍可召回"的回归测试。

### 第二轮审查（2026-11-03）

4. **[高] 决定历史无法表示"改回原决定"**：`keep→replace→keep` 第三次命中第一次的内容哈希 ID，只剩两条记录，无法区分"改回"与"重复调用"，也无法判定最终决定。修复：`add_change` 改为审查事件模型——`revision`（链内修订序号）+ `seq`（全局序号）标识每次事件，`review_id` 单独承担重试幂等（同 ID 重放返回原记录、同 ID 改决策报错），序列化升 version 3 并兼容加载 version 1/2（各自旧公式校验后重编码）；`trace` 按 `seq` 返回事件顺序。新增：改回三事件+重试幂等+矛盾重试拒绝、手写 v2 负载加载、变更历史 pickle 往返测试。

## 已知限制

- 事实检索入口为「图匹配实体 + 原始查询实体」的精确（casefold）匹配加别名，无语义召回；问题未提及的图外实体仍不可达。
- 无 `review_id` 的 `add_change` 调用每次都追加新事件：**审查流水线重放时必须传 `review_id` 才幂等**（当前无生产调用方，模型审查属后续工作）。
- 同 (src, relation, tgt, evidence) 重复抽取以最后一次 `raw` 为准（同 ID 幂等覆盖；`source_chunk_id` 保留最近一次写入的处理序号）。
- 未在真实模型抽取下验证端到端；LoCoMo / LongMemEval 实测为下一步（数据集转换脚本已存在，需配置模型服务后执行）。
- `_dynamic_add_chunks` 为弃用路径，本次仅补命名空间防护，主路径为 `add_single_session`。
